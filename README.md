# CourseMatch

AI destekli üniversiteler arası ders eşdeğerlik ve müfredat karşılaştırma sistemi.

## Teknoloji Stack

- Frontend: React + Vite + TypeScript
- Backend: FastAPI + Python
- Database: PostgreSQL
- Container: Docker Compose

## Geliştirme Ortamı

Frontend:
http://localhost:5173

Backend:
http://localhost:8000

API Docs:
http://localhost:8000/docs

## İlk Hedef

Manuel ders ekleme, ders listeleme ve iki ders arasında temel benzerlik karşılaştırması.
